# SEC-08 → Vinteum

Apresentação de Breno Brito sobre o SEC-08, a residência de seis semanas do [Sovereign Engineering](https://sovereignengineering.io) em Madeira (20 de julho a 28 de agosto de 2026), preparada para uma conversa com a comunidade Vinteum.

**Slides:** https://brenorb.github.io/soveng-sec08/

## Como usar

É uma página única (`index.html`), sem build e sem dependências de rede. Para ver localmente, abra o arquivo no navegador.

- **← / →** (ou PageUp / PageDown): navegar. **Home / End**: primeiro e último slide.
- O seletor na barra de baixo pula para qualquer slide.
- Para imprimir ou exportar em PDF: use o diálogo de impressão do navegador, tamanho A4 em paisagem, sem cabeçalhos e rodapés, com gráficos de fundo ativados.
